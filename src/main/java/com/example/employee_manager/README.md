# Employee Management System

A Spring Boot CRUD application with MySQL and Lombok.

## Prerequisites
* Java JDK 21 or later
* XAMPP MySQL Server
* Maven

## How to Run
1. Start the MySQL and Apache server in XAMPP.
2. Create the database- employee_db.
3. Run the program.
4. Check CRUD operations using postman.
    URL-http://localhost:8080/employees
